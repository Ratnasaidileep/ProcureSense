# ProcureSense

## Intelligent Public Procurement Analytics Platform

ProcureSense is an end-to-end Data Analytics project that analyzes government procurement data to identify spending patterns, vendor concentration, procurement trends, and potential procurement risks.

The project demonstrates a complete analytics workflow from raw data ingestion to interactive business dashboards.
