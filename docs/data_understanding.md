# ProcureSense - Data Understanding

## Dataset Information

Dataset Name:
Government Procurement Dataset

Number of Rows:
32757

Number of Columns:
7

Columns

1. tender_no
Description:
Unique tender identifier.

Data Type:
String

2. tender_description

Description:
Procurement description.

Data Type:
Text

3. agency

Description:
Government agency issuing the tender.

Data Type:
String

4. award_date

Description:
Tender award date.

Data Type:
Date

5. tender_detail_status

Description:
Award status.

Data Type:
Categorical

6. supplier_name

Description:
Winning supplier.

Data Type:
String

7. awarded_amt

Description:
Awarded contract amount.

Data Type:
Decimal

Potential Business Questions

- Which agency spends the most?
- Which suppliers receive the highest value contracts?
- What is the monthly spending trend?
- Which contracts have unusually high values?
- Which agencies have the largest average contract values?
- How many tenders were not awarded?
- Which suppliers work with multiple agencies?
